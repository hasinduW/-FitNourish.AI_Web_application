Project Scope

Literature Survey

Existing research shows that personalized nutrition is increasingly important in digital health. Traditional methods mainly rely on fixed equations and limited demographic variables, while modern research supports richer feature integration, including physiological and activity-related signals. Advances in machine learning, multi-output prediction, and explainable AI make it possible to build nutrition systems that are more accurate, adaptive, and user-centered than traditional estimation methods.

Research Gap

Many nutrition systems still depend on static formulas, narrow feature sets, calorie-only outputs, and weak interpretability. There is still a clear need for a system that combines demographic, physiological, activity-related, and health-aware data while producing a complete and explainable nutrition profile.

Research Problem & Solution

The key research problem is that personalized nutrition requirements are difficult to estimate accurately using generalized traditional methods. FitNourish AI addresses this by using an XGBoost-based multi-output regression framework that predicts calorie and macronutrient needs from structured user-specific data and supports interpretability through SHAP-based explanation.

Research Objectives

Main Objective

To design and implement a machine learning-based multi-output prediction system that estimates personalized nutritional requirements using demographic, physiological, activity-related, and health-condition user data.

Specific Objectives

  • Collect and organize relevant user-specific data
  • Apply preprocessing and feature engineering
  • Train a multi-output XGBoost-based nutrition model
  • Evaluate predictive performance and generalization
  • Improve transparency using SHAP-based explainability

Methodology

The methodology combines structured user data, preprocessing, feature engineering, nutritional baseline logic, XGBoost-based multi-output regression, evaluation, and explainable AI.

1

Data Collection

Demographic, physiological, activity, health, and goal-related data were collected.

2

Preprocessing

Missing-value handling, cleaning, categorical encoding, numerical scaling, and splitting.

3

Feature Engineering

BMI, Activity Ratio, Heart Efficiency, Steps per Minute, and Stress Impact were created.

4

Prediction Model

XGBoost with MultiOutputRegressor was used to predict calories and macronutrients.

5

Interpretation

SHAP was used to improve transparency and support explainable nutrition prediction.
